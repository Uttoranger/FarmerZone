System · Titelbild

Sechs Filter, nur CSS

Ein Hof wählt einen Filter mit einem Tipper; die Plattform speichert nur den Namen. Dasselbe Foto, derselbe Ausschnitt (Fokus 50 / 66, Zoom 100 %).

Natürlich
filter: none
Enum NATUERLICH
Klar
filter: contrast(1.08) brightness(1.03) saturate(1.05)
Enum KLAR
Warm
filter: sepia(0.22) saturate(1.2)
Enum WARM
Kräftig
filter: contrast(1.12) saturate(1.35)
Enum KRAEFTIG
Sanft
filter: contrast(0.9) brightness(1.07) saturate(0.85)
Enum SANFT
Schwarzweiß
filter: grayscale(1) contrast(1.1)
Enum SCHWARZWEISS
· Sechs feste Filter, nur CSS – keine zweite Bilddatei, keine Verarbeitung am Server. Gespeichert wird der Name (Enum), die CSS-Zeichenkette steht einmal in lib/titelbild.ts.
· Der Filter gilt für Foto und unscharfe Kopie gleich (Kopie: blur(28px) plus Filter), am Computer wie am Handy, in Mein Hof wie auf der Hofseite und im Teilen-Bild.
· Reihenfolge wie hier; „Natürlich“ ist Standard und entfernt den Filter. Vorschau-Kacheln zeigen immer dasselbe Stück des Fotos, damit der Unterschied erkennbar ist.
· Kontrast der Schrift auf dem Handy-Titelbild bleibt durch den dunklen Schleier gesichert – kein Filter hellt die untere Kante auf.
