Anmelden: Hof und Admin · Web hell

Eine Seite für beide Wege: Kundinnen mit Code (ohne Passwort), Höfe mit Passwort oder Passkey. Am Handy wählt der Umschalter oben den Weg, im Web stehen beide Karten nebeneinander; „Anmelden“ ist für Höfe die eine Hauptaktion (orange), der Passkey ein Umriss. Der Fehler verrät nicht, ob es das Konto gibt. Admin hat eine eigene Seite ohne Passwort und ohne Mail-Code (N20). Den Weg der Kundschaft zeigt s2-kundenkonto. Die Hof-Karte bleibt orange, auch in der KundeShell: Sie ist der Einstieg in den Hofbereich (wie im Code). Seitenfuß wie in der KundeShell (N22).
