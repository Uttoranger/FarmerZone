Meine Bestellungen (Kundschaft) · Web hell

Ohne Konto: E-Mail, 6-stelliger Code, dann die Liste – nur für diesen Besuch. Formular in einer Karte, je Schritt eine Hauptaktion. Ein unvollständiger Code ist ein Feldfehler (orange, aria-invalid). „Code erneut senden“ erst nach 30 Sekunden. Die Liste trennt „Aktuell“ und „Früher“. Jeder Zustand hat sein eigenes Bild: leer, Ladefehler, abgelaufen.
