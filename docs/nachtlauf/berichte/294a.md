# Bericht 294a – Vorschau-Build bricht ab, wenn er auf die Produktions-Datenbank zeigt (M7)

Lauf 34, Abschnitt B. Branch nacht/2026-11-11/294a-vorschau-db-wache, Basis integration/lauf34b 3a980467d70e (mit 285, 288, 290, 294b). Migration: nein. Kein Paket, keine Variable. Startsatz: keiner.

## Befund (Ursache, Auswirkung, Fix)
Ursache: `vercel-build` spielt in jeder Umgebung zuerst die Migrationen ein, Ziel `DIRECT_URL`, sonst `DATABASE_URL`; eine Vorschau mit einer Variable der Produktion erzeugte nur einen Satz im Banner. Auswirkung: Ein Fehlgriff bei den Variablen in Vercel hätte die Migration eines ungemergten Branches in die Produktion gespielt. Fix: eine Prüfung als erster Schritt von `vercel-build`, die genau diesen Fall mit Ausgang 1 abbricht und sonst immer durchlässt.

Variablen in Vercel prüfen.“ nach stderr und endet mit 1, jeder andere Weg und jeder Fehler mit 0 (Fehler wird nicht ausgegeben, er könnte die Adresse tragen).
