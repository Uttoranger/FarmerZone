# Nr. 184 — Signal statt Lärm, `/api/gesund`, Lebenszeichen alle 15 Minuten (Lauf 26)

Ausgangslage am Code bestätigt: Die Meldung „Umgebung widersprüchlich …“ ging nur „einmal je Instanz“ (Modul-Merker), `/api/gesund` fehlte, das Lebenszeichen lief täglich `17 7 * * *`, Admin › Betrieb hatte weder Dienste noch Version noch Alarm-Matrix. Kein STOPP. Migration: nein · Paket: nein · Variable: nein (`VERCEL_GIT_COMMIT_SHA` setzt Vercel selbst).

## Ursache JAVASCRIPT-NEXTJS-7 (Sentry gelesen)
- **Wo:** `meldeUmgebungsWarnungen` in `src/lib/umgebung-server.ts`; einziger Aufrufer `UmgebungsBanner` (`src/components/shared/umgebungs-banner.tsx`) im Root-Layout, also bei jedem Seitenaufbau jeder Seite.
- **Wie oft:** 1 553 Ereignisse vom 2. bis 26.10.2026 (rund 65 am Tag), ein Zustand (Stripe Test in Produktion, kein Connect-Secret). Der Merker war ein Modul-Wert: Jede neue Vercel-Instanz (Kaltstart, Deploy, Skalierung) meldete von vorn.
- **Fix:** höchstens einmal je UTC-Tag und Deploy — je Instanz ein Tag-Merker, über alle Instanzen eine Zeile `sentry:<zustand>:<deploy>` in `BetriebMessung` (ON CONFLICT DO NOTHING), gemeldet nach der Antwort. Banner, Betriebsleiste und Admin › Betrieb zeigen den Zustand weiter.
