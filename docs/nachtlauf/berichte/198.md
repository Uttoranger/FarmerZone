## Monatsablauf und Stripe-Ereignisse
Ankündigung 28 Tage vor `einzugAbFuer` (einmal: `gebuehrHinweisAm`, Postfach SYSTEM + Mail) → Abrechnungstag (Wien, Vorgabe 3.): Upsert `Monatsabrechnung`, Rechnung online `paid_out_of_band`, Rechnung bar (Lastschrift `charge_automatically` mit `sepaZahlungsmittelId`, ohne Pflicht `send_invoice`/`days_until_due`) → `invoice.paid` = bezahlt → `invoice.payment_failed` = gescheitert, `offenSeit`, Postfach + Mail je Versuch → nach `barSperreNachTagen` bzw. `charge.dispute.created` sofort: bar aus (409, Kasse nur online, Heute-Karte „Jetzt bezahlen“) → `invoice.paid` = frei. Mandat: `setup_intent.succeeded` setzt es, `mandate.updated` inactive nimmt es.
